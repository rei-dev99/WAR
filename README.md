# 🃏 トランプゲームの戦争
アプレンティスの課題「トランプゲームの戦争」

## 概要
2〜5人のプレイヤーで遊べるトランプゲーム「戦争」をRubyで実装しています。

### ゲームルール
- カード構成: 52枚、ジョーカーなし
- プレイヤー人数: 2〜5人
- 配布: カードをシャッフルし、全プレイヤーに均等に配ります。
- 全プレイヤーが「戦争！」の掛け声とともにカードを1枚出します。
- 出されたカードの中で、最も強いカードを出したプレイヤーがその場のカードをすべて獲得します。
- 引き分けの場合、その場のカードは次の勝者が出るまで場に保持されます。
- カードは強い方から、A、K、Q、J、10、9、8、7、6、5、4、3、2 の順番とします。

#### ラウンド制限
勝負が長引いて決まらないことがあるため、ラウンドを50までとしています。
ラウンドが50に達した場合、持っているカードの枚数と脱落順によってプレイヤーの順位が決まります。

### 実行方法
1. このリポジトリをクローンします。
2. Rubyがインストールされていることを確認します。
3. 以下のコマンドを実行してゲームを開始します。

```
ruby main.rb
```

プレイヤー人数と名前の入力をすると「戦争！」の掛け声とともにゲームが始まります。

カードが最後の一人に集まるか、50ラウンド経過した時点で戦争が終了し、結果が表示されます。
